# Database

PostgreSQL 17 with PostGIS, pg_trgm and citext. See
[ADR-002](../adr/002-postgresql-postgis.md) for why.

## Migrations

- Location: `backend/src/main/resources/db/migration`.
- Naming: `V<n>__<what_changes>.sql`, one logical change per file.
- Merged migrations are never edited; fix forward with a new migration.
- Hibernate runs with `ddl-auto=validate`: it checks the mapping against the
  schema and never changes it.
- Every CI build migrates an empty PostGIS database from `V1` (see
  `FlywayMigrationIT`), so the migration chain stays reproducible.

| Version | Change |
| --- | --- |
| V1 | Baseline: enable `postgis`, `pg_trgm`, `citext` |

## Conventions

- Primary keys: `uuid`, generated by the application (time-ordered), except
  reference tables keyed by a natural code (`categories.code`).
- Timestamps: `timestamptz`, stored in UTC.
- Enumerations: `text` with a `CHECK` constraint (easier to evolve than a
  PostgreSQL enum type).
- Locations: `geography(Point, 4326)`.
- Every foreign key column gets an index unless a composite index already
  starts with it.

The ER diagram and index rationale are added as the schema grows (Phases 2–4).
